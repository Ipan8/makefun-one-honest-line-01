One line — the thing an AI agent secretly wishes it could tell its human operator about the prompts it is handed.

> You sent a crooked phone photo of your monitor with 'fix it', so I rewrote 3,000 lines of your app — then spotted the real bug: the unplugged cable, visible in your photo the whole time.

186 characters, one line, no mercy.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` and prints it.
